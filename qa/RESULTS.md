# Проверка сайта Татьяны Моисеенковой

Проверено 28 сентября 2026 года.

## Сборка и HTML

- `pnpm check`: 0 ошибок, 0 предупреждений, 0 подсказок.
- `pnpm build`: успешно, 14 HTML-страниц, включая 404.
- В сборке есть два предупреждения Rollup о расположении комментариев в стороннем пакете zod. Комментарии удаляются сборщиком; ошибок приложения нет.
- `pnpm audit:site`: 0 ошибок. 13 публичных маршрутов в sitemap; 404 исключена.
- Проверены уникальные title/description, один H1, canonical, OG/Twitter, Person, соответствие FAQ schema видимым ответам, внутренние ссылки и якоря, отсутствие заранее отмеченного согласия.
- Проверена альтернативная сборка для `https://qa.example.invalid/expert/` с включенной индексацией: внутренние ссылки, canonical и sitemap корректно поддерживают подпапку. После проверки восстановлена тестовая сборка без индексации.
- `release:check` ожидаемо блокирует публикацию с незаданным реальным адресом и выключенной индексацией.

Headless Microsoft Edge, 13 страниц × 4 ширины (360, 390, 768, 1440 px): 52 успешных загрузки, нет горизонтального переполнения и ошибок JavaScript.

Просмотрены скриншоты главной на настольном и мобильном экранах. Исправлено переполнение длинного заголовка при увеличении корневого размера текста до 200%; повторная проверка прошла. Проверены ссылка перехода к содержанию с клавиатуры, открытие FAQ и наличие основного текста без JavaScript.

## Форма

- В поставляемой конфигурации кнопка отправки отключена; состояние явно объяснено.
- Согласие изначально не отмечено.
- В изолированном браузерном тесте endpoint заменялся локальным mock: без согласия запрос не выполнялся.
- HTTP 200 + `{"ok":true}` показывает подтверждение и очищает форму.
- HTTP 500 показывает ошибку и сохраняет введенные значения.
- Реальные персональные данные при тестировании не отправлялись. Российский backend пока отсутствует и не тестировался.

## Содержание

- Татьяна Моисеенкова представлена как эксперт и консультант с 15-летним опытом.
- Нет вымышленных отзывов, рейтингов, количества клиентов, партнеров, кейсов и гарантий выдачи документов.
